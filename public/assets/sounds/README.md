# Notification sound

- Source: [Kenney Interface Sounds 1.0](https://kenney.nl/assets/interface-sounds), `Audio/confirmation_001.ogg`.
- License: CC0 1.0; the original pack's license notice is retained in `LICENSE.txt`.
- `notification.mp4` is an audio-only MP4 with AAC encoding, converted using FFmpeg at 96 kbps with faststart and metadata removed.
- The app serves the file locally, decodes it once after user interaction and plays it at 20% gain for new unread notifications. No third-party runtime request is needed.
